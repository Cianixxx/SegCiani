# Core SliceLens has NO third-party dependencies -- the algorithms and the
# offline mock backends run on the Python standard library alone:
#
#     python examples/demo_mock.py
#
# Install the real backends only when you need them (preferably on the GPU
# server). Pick via the pyproject extras, e.g.:
#
#     pip install -e ".[gemini,qwen]"     # Gemini-2.5-Pro + Qwen2.5-VL-7B
#     pip install -e ".[dev]"             # pytest
#
# Or install the packages directly:
#
# --- Hypothesis generation LLM (Gemini-2.5-Pro, paper default) ---
# google-genai>=0.3.0
#
# --- Slice-confidence VLM (Qwen2.5-VL-7B, paper default) ---
# torch>=2.1
# transformers>=4.49
# accelerate>=0.30
# qwen-vl-utils>=0.0.8
# pillow>=9.0
#
# --- Optional faster VLM serving (paper deployment) ---
# vllm>=0.6
#
# --- Tests ---
# pytest>=7
